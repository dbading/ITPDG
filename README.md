# Interaktive Mathematik-Animationen

Eine Sammlung interaktiver Mathematik-Visualisierungen für Studium und Lehre.

## Fourier-Reihe

Mit dem Slider kann die Anzahl der Fourier-Moden von \(N=0\) bis \(N=20\) eingestellt werden. Die ursprüngliche Funktion und die Fourier-Approximation werden gemeinsam dargestellt.

**[Zur interaktiven Animation](fourier_interaktiv.html)**

## Verwendung

- `index.html` ist die Startseite der GitHub-Pages-Website.
- `fourier_interaktiv.html` ist die eigenständige Animation.
- Die Animation funktioniert ohne Python-Server und ohne externe Bibliotheken.

Die HTML-Dateien können direkt lokal im Browser geöffnet oder über GitHub Pages veröffentlicht werden.

## GitHub Pages aktivieren

Im Repository unter **Settings → Pages** bei **Source** `Deploy from a branch` auswählen und `main` sowie `/(root)` einstellen, dann speichern.

Danach ist die Seite unter `https://BENUTZERNAME.github.io/math-animations/` erreichbar (BENUTZERNAME ersetzen).
